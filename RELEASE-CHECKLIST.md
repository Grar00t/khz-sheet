# Release gate
Development use: PARTIALLY VERIFIED for the exercised native subset. Controlled beta, arbitrary untrusted XLSX, financial decisions, integrity-sensitive records and end-user desktop suitability: NOT VERIFIED.
The three KhzBoundaryContracts modes pass against the current Windows DLL. Before broad release, still require full ABI field-offset/alignment tests; verify atomic desktop edit/open/save failures; complete XML/OPC validation beyond the exercised ZIP boundaries; and test the actual supported locales and accessibility workflows.
Tables, charts, most requested formula functions and localization are absent, not implicitly supported. Do not advertise them. Require independent OOXML consumer validation for each exported feature and payload-hash preservation for untouched parts.
Run clean GCC/Clang/MSVC builds, ledger-off native tests, full WPF interaction, accessibility checks and same-host reproducibility before broader promotion. The final local gate covered ASAN+UBSAN, ledger-on portable/AVX2 tests, the rational oracle, .NET build, managed boundary regressions, desktop build/startup and PQC encrypt/decrypt/signature round-trip. Hosted CI success remains a separate evidence layer.
