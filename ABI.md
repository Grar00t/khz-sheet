# ABI boundary
Current native ABI is 96. This patch does not change public structures, enum values, exported signatures or calling conventions. The private wide-arithmetic header has no exported surface. Managed bindings accept historical versions 91..96, but only the current library was executed here.
P/Invoke declarations use Cdecl. Rational/cell mirrors and selected sizes/offsets are checked through the existing ABI report. This is not exhaustive offsetof/alignment verification of every public field. Native strings are UTF-8 with explicit byte lengths. Arena-backed pointers are borrowed and become invalid at owner destruction or arena rewind.
Sheet mutation requires external serialization; concurrent mutation of one sheet is not supported. Ordinary NativeSheet ownership has not been migrated to SafeHandle. Existing disposal tests do not prove all finalizer/GC races safe.
The final source uses a lock to publish ABI verification results atomically and maps BadImageFormatException to ErrUnsupported. `NativeSheetFormula` evaluates/declares managed ASTs in a separate bounded 1 MiB arena owned by NativeScratchArena (SafeHandle). Persistent dependency edges remain in the sheet arena after scratch IR is abandoned.
The three KhzBoundaryContracts modes now pass against the final Windows DLL: arena lifetime plus reuse/double-disposal, eight concurrent first-verification callers, and a malformed library image. These are regression results, not a signature/authenticity check of the DLL or complete concurrent-sheet safety.
Raw IntPtr-based KhzFormula entry points still require callers to supply independent scratch storage and valid pointers. The new wrapper allocates a scratch arena per call; its managed-performance cost was not benchmarked. Other NativeSheet ownership remains unchanged.
