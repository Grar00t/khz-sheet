# Desktop boundary
The existing WPF shell compiles for net8.0-windows and uses a bounded DataTable view over the native sheet. `WorkbookSession.cs` owns session integration; native semantics remain in C.
The desktop now has single-cell semantic Undo/Redo through the ordinary commit path, case-insensitive Find Next over stored inputs/formula source, a first-column freeze toggle, an application icon/header mark, and `Copy Proof`, which re-verifies the current proof chain before putting the proof hex on the Windows clipboard. Transactional rectangular paste, grouped Replace All history, unsaved-change workflow, atomic save, CSV safety hardening, asynchronous import, table UI and chart UI remain absent.
The final Windows desktop build exits successfully with zero C# warnings/errors, and the executable remains running during a three-second startup smoke test before an orderly close. Button-level UI automation was not executed. End-user reliability, accessibility, scroll responsiveness and Arabic/RTL behavior remain separate unverified layers.
