# Accessibility

The desktop supplies standard WPF controls, header selection indicators and a High Contrast preset. Chart views expose UI Automation names and exact-fraction data descriptions. `KhzSubsystemContracts` checks those descriptions, keyboard-focused grid editing and the minimum window layout; it renders all four themes for visual inspection.

This is limited interaction evidence. A screen-reader task walkthrough, complete focus-order audit, keyboard-only open/save workflow, system high-contrast integration and long-string/Arabic RTL layout assessment have not been completed. No accessibility standard conformance is claimed. Table filter controls are not implemented.
