# Native XLSX boundary
The writer emits STORED ZIP members and a narrow single-sheet workbook. The reader accepts STORED and raw DEFLATE members, checks CRC, and parses supported workbook/worksheet/shared-string content. It does not implement the whole OOXML schema.
The ZIP loader now rejects conflicting local metadata, duplicate/ASCII-case-colliding names, overlapping member extents, nonzero member disk numbers, unsupported flags/encryption, embedded NUL/control/path ambiguity and inconsistent data descriptors. Signed and unsigned 32-bit data descriptors are tested. ZIP64, digital-signature records between the central directory and EOCD, and percent-encoded part-name interpretation are not supported by this narrow profile.
Default compile-time ceilings: archive 256 MiB; member output 64 MiB; total member output 128 MiB; expansion ratio 1000:1; 64 members; 512 name bytes. Archive/part/total/ratio macros in `khz_xlsx_reader.h` can be overridden at compilation. Exceeding resource ceilings returns ERR_LIMIT. Malformed framing returns ERR_FORMAT; selected unsupported features return ERR_UNSUPPORTED. The supplied arena remains an additional allocation limit.
Duplicate-name comparison folds ASCII letters only. It is not Unicode normalization or complete OPC URI equivalence. Directory separators are forward slashes; empty interior segments, dot segments, backslashes, colon, percent, query and fragment characters are refused.
The XML parser still lacks a comprehensive namespace-aware grammar and full depth/token/relationship budgets. Native load success alone is not sufficient grounds to trust arbitrary untrusted XLSX files.
Numeric export uses the existing XLSX conversion boundary and can lose rational exactness. No binary64-free round-trip of arbitrary rational numbers is claimed. Formula text and supported strings have existing tests; tables, charts, styles and all external-consumer behavior are not demonstrated.
Format reference: PKWARE APPNOTE 6.3.10, sections 4.3.7, 4.3.9 and 4.3.12. The implementation is deliberately narrower than general ZIP.
