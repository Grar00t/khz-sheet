# Localization
Workbook text uses the existing Unicode/UTF-8 boundaries; internal A1/formula syntax is invariant. This is distinct from UI localization.
The desktop retains English user-facing text. It has no complete English/Arabic resource catalog, persistent language selector, localization-key parity test, placeholder validation, Arabic digit display policy or verified RTL navigation.
Arabic text rendering, combining-mark behavior, IME input and mixed-direction chart/table controls have not been exercised in a visual test. No normalization of user text was added. English workflow text presence is not comprehensive English localization support.
