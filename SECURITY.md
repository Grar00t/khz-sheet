# Security boundary
This revision is not approved for arbitrary untrusted workbooks. Native ZIP validation is stronger, but complete XML/OPC validation and sustained fuzz coverage are not established. Three reproduced managed boundary defects pass their final regression tests; ABI.md describes the fixes and remaining ownership/ABI limits. This does not establish memory safety for every managed API.
Report a defect with the exact commit, platform, minimal synthetic reproducer, expected/observed status and sanitizer output. Do not attach real workbooks, customer records or secrets. No dedicated private vulnerability reporting channel is established by this document.
The library does not add telemetry, network services or runtime dependencies in this intervention. Optional release packaging is documented separately in PQC-RELEASE.md and is a development/distribution tool, not a workbook-encryption feature. Integrity hashes are not encryption or a compliance determination. Normal missing features are not classified as vulnerabilities.
